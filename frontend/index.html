ML Model Validation & Benchmark Evaluation

Rigorous chronological time-series evaluation (70% train / 30% test split, no future lookahead leakage).

Important ML Engineering Finding: On this bundled benchmark dataset, Linear Regression achieves lower MAE than Random Forest (Solar: 0.0001 MW vs 0.0012 MW; Wind: 0.0010 MW vs 0.0178 MW) because the synthetic benchmark power generation was synthesized using exact affine linear equations without measurement noise. However, in actual utility-scale renewable plants, Random Forest is technically essential to capture real-world non-linear physics (inverter MPPT clipping, temperature derating coefficients, and wind aerodynamic cubic curves).
